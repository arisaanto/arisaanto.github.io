# Splatdex

A public portfolio viewer for Gaussian splats. Browse the catalogs, save objects, arrange a personal collection, and attach notes to views. Collection changes are stored in the visitor's browser. The optional language model runs on the visitor's device after its initial download.

Model credits, licenses, and original capture links are available in each object's About panel. The iPhone capture and Mac reconstruction workflow is presented separately on the Splatdex project page.
